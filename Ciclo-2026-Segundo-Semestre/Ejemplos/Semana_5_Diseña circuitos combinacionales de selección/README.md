# Ejemplo de MUX y DEMUX en una ALU con Proteus

Este proyecto es un ejemplo de simulación en Proteus para mostrar cómo se pueden usar un multiplexor (MUX) y un demultiplexor (DEMUX) en una unidad aritmética y lógica (ALU).

## MUX

El MUX selecciona una de varias señales de entrada y la envía a una sola salida. En una ALU, puede elegir qué resultado se utiliza, por ejemplo, el de una suma o el de una operación lógica. Las entradas de selección determinan cuál resultado pasa.

## DEMUX

El DEMUX toma una señal de entrada y la envía a una de varias salidas. En una ALU, puede dirigir una señal hacia una salida específica, de acuerdo con las entradas de selección.

## Que observar en la simulacion

Al cambiar las entradas de selección en Proteus, cambia la entrada elegida por el MUX o la salida que recibe la señal del DEMUX. Así se observa cómo estos circuitos ayudan a seleccionar y dirigir datos dentro de una ALU.
